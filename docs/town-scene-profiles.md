# 町原画与店铺入口

`town.scene-profiles.v1` 是 ROM 内目录资源，不按发行版名称分支。原生渲染756C区分普通町、堺／難波、京／大和三套图块映射；同一图块代码在不同套中不是同一幅画。读取资源的 `town_profiles` 与 `profiles.art_table`，缺省保留原版9/10/11/12的模式。

`town_buildings` 声明完整图块矩形及门口相对位置。设施绑定指向原生6字节设施记录的scene/x/y；具名住民绑定指向`town.residents.v1`的24字节记录偏移20。编辑器验证绑定确属对应原生表，然后从当前门口反算矩形，因此拖动、撤销及导出后重新载入都有效。移动时只改图块和scene/x/y，不改人物身份、职业或存档字段。

洲本采用原生港町图块，建筑全部重新排布；新增六名住民具有独立状态。状态在已有FEX快照中，编辑器不会将其并入旧的20人数组。港町绘制面板排除普通町专用的屋顶／黑块代码。原版图像和ROM不随仓库发布。
