# 地图浏览、城池属性与势力关系（2026-11-03）

## 界面

“城池”模块改名“地图浏览”，默认地图模式；目录同时含125条城池资料（其中2条剧情异名）及17个町，对应123城、17町。目录可筛城/町，图标直接使用当前ROM图块；城池按开局规模绘制，规模用Ⅰ～Ⅳ表示，不冒充尚未核对的游戏规模名称。町使用实际入口原码，复式入口均可点击。地图上去掉通用菱形，直接点击已有城/町造型。悬停或键盘聚焦使用图形占位范围的矩形发光描边，并非按像素抠图的轮廓；保留原画及大小差异。

城池详情先显示所属势力、城主、坐标、规模、资源军备、邻接，最后武将。编辑弹窗基本信息在上、名称和九项属性在中、武将在后。归属与城主保持只读。町独立展示坐标与出入口，不套用城池经济属性。

势力详情按真正开局势力表展示大名、本城、领城；外交表使用游戏原文关系标签，逐方向显示。盟/属为附加原标记，不把友好度与盟约混为一项。位3婚姻标记尚不解释为具体婚姻对象。首字节0或FF在月度分派中跳过，故预留势力槽位标为未启用，不把其预填关系当已登场势力。浪人分组不显示大名外交记录。

## 字段证据

游戏17E48将ROM7AAB8的123×18字节复制到FF3D6C。1AE9C复制城池资源到12字节详情快照，1AF80显示城池详情；1B102..1B176验证资金、兵粮的十倍显示单位，1B188..1B1CE验证骑马、铁炮的百倍显示单位。编辑字段如下：

|状态偏移|含义|界面单位/约束|
|---|---|---|
|+3|石高|万石；byte|
|+4|统治|%；0～100|
|+6|资金|word×10贯；输入10的倍数，raw≤30000|
|+8|兵粮|word×10石；输入10的倍数，raw≤30000|
|+10|铁炮|byte×100丁|
|+11|骑马|byte×100头|
|+12|兵士|word人；编辑上限30000|
|+14|士气|%；0～100|
|+15低2位|城池规模|0～3；保留高6位|

上限为当前编辑器的校验策略，不声称所有值均是引擎硬上限。+0城ID、+1城主槽、+2势力及+5/+16/+17等不因本功能改写。123/124剧情异名按坐标映射到79/91的同一运行记录；不能为异名制造新状态。

ROM85A7A的20×34字节复制到FF0248。势力+0大名槽、+21本城，+1..+20为对目标0..19的关系。8DAE..8DF8与1A016..1A030按低3位索引76428原字符串指针表：盟友/親密/良好/通常/敵視/敵対/交戦。高位附加符号表BFC86在游戏内列－/盟/属；两方向分别读取，不强制镜像，不开放编辑。
