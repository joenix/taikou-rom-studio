# 势力图绘制

载入 v1.42.12 势力绘图ROM → 地图 → 势力图绘制 → 顶部钥匙解锁。

- 先用「陆地・点阵」中的原版图块铺画，海岸和海面也有原版图块可选。画笔1/2/4/8px；右键或吸色工具取当前底图颜色。
- 组合取样：在原版参考区或西端拖框（最大32×32），再到西端盖章，城点/道路颜色会忽略。
- 选区拖框后填色或还原。还原来自此次载入的文件；原文件不覆盖，修改可撤销/重做。按住对比可查看导入时图像。
- 左侧西端128×224像素可画；其余原版区域、城点和道路受保护。这不是大地图地形编辑。
- 缩放2/4/8/12/16倍，网格在高倍显示像素。拖动模式可平移。手机只能拖动缩放浏览。
- 顶部导出ROM保存。刷新会保存工作副本但重新锁定，撤销历史不会跨刷新；还原基准会保存。导出文件可回传Codex回收进构建。
- 自绘图案容量63种，支持图案翻转/复用；超量会整笔拒绝，尽量使用原版图块与重复纹理。

适配按ROM resources.faction_overview/schema识别，不依赖发行文件名。缺失标记时不猜地址。配套版 overview-only 仅开放势力图写入，其余资料只读。
