# 宝物真实图标（v1.40.02）

支持20个原生32×32图标。编辑窗直接展示图像，点击预览；应用、撤销、重做、导出与重新载入均使用ROM工作副本。原始文件不写入。首次实际改变图标时追加316字节（16字节版本头和300字节逐宝物图标表），不新增宝物数量、不改运行容量。

已核对的读取函数为0x54E34：0x54E4C原指令取定义表+13，即0x88F3F；0x54E52使用D0.L（ID×14）读取。0x54E44已将未乘14的ID保存在D1。编辑器仅把图像读取改为独立表基址与D1.L索引。20个压缩图像指针在0xE2BFE，图像位于0xE0A68起；原色板0x8A2C0。全部20个图像均解码为32×32。

原+13仍参与0x54F42的类别显示判断。因此原14字节定义完全保留，图像变更不能直接覆盖+13；独立引用只供0x54E34绘图函数使用，其他业务消费者不改。

实现：src/rom/item-icons.js。布局头TKICON01，count=300/version=1；指令指纹、目录范围、每个图标编号与图像尺寸均校验。新图标表可与町扩展先后安装；目录位置只在符合这两种精确布局时接纳，不放宽成任意尾部数据。

验证：tests/item-icons.test.js覆盖逐条写回、原类别/效果字节保留、撤销重做、导出重载、损坏拒绝及与地图扩展的两种安装顺序。docs/evidence/item-icon-native.json记录实际游戏中重开所持列表、进入闘戦経详情，机器码确实以ID51读到新图标1。build/item-icon-game.png显示茶器图，原名称、漢書类别、金20貫、价值1保留。原存档SHA不变。此为现有物品详情路径验证，不等于所有玩法全回归。

局限：不导入自定义图片，不编辑图像像素，不新增图标种类；不改变宝物类别、效果或数量。测试生成的BIN是诊断副本，未作为新正式版本发布。
