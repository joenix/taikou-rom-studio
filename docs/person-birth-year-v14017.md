# 人物列表生年与1.40.17支持

人物列表保留编号、姓名、初始势力、居城、身份、出生年；移除相性/战术/政略列及对应列表排序，属性仍在详情。出生年可升序排列，未知值排末尾显示—，详情标为“出生年（配置）”。

日期从载入ROM的TKAMEND1定位器/TKAM6001中按全局ID读取，非网页内置历史名单。包含历史研究推定和设计配置，不代表历史确年或已启用按年登场。既有町扩展originalLength、宝物图标追加边界均可定位原日期尾标；范围/结构/月份和加载时SHA256校验，损坏明确拒绝。只读显示，不写生年或重算登场机制。

新增1.40.17标题及实际船行关键指令指纹，仍校验原修复和基础资料布局；不只放宽名称正则。实际17载入通过，木下1536/织田1534/上杉1530；45项测试与Vite构建通过。尚未做浏览器布局检查，未线上发布。

能力边界：现有城位置/名称/九类状态字段可改；没有新增独立城池或增加城池运行表的API。独立町实验扩容仅1个，17静态townCapability支持不等于17游戏内新增町全流程已验收。
