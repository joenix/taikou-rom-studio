# 大地图原画静态预览（2026-11-03）

当前ROM读取压缩图像、地形映射、城池映射和调色板；不内置网上截图或拼接地图背景。城池地图浏览与地图工坊共用NativeWorldCanvas，只绘制可见窗口，滚动由requestAnimationFrame合并，图块缓存复用。原画、交互两张画布在16倍时均实测907×452，没有为整图分配5248×3072画布。原来的示意配色可切换保留。

## 原生证据

机器码D426：普通格从CF52E按原码查图块起号；D37E把连续4个8×8图块按2×2拼为16×16，使用色板1。Castle表CF5DC有8种样式，每项4个word，分别为左上、右上、左下、右下；城池占上下两格、左右两格。右半由原码bit3选择，样式取(code>>4)&7。C10A及DC740按城RAM+15低两位与玩家关系生成城原码高位。

E614E的long指向E2CA6压缩图像，解压11264字节=352个8×8图块，上传VRAM5A40。解压结果与供给存档运行时对应VRAM逐字节一致。用ROM映射和RAM现场重新计算D426所绘210个逻辑格，共844个实际覆盖的图块属性word，与原生缓冲FFCFB0比较，差异0。未覆盖缓冲word不计独立验证。证据docs/evidence/world-art-native.json。

日间四组调色板在8A5A0起，每组32字节。74CA按(month%12)//3选组：冬/春/夏/秋。当前五月存档对应春8A5C0，与CRAM色板1的前15色一致；末色与存档现场不同，写入来源和原因尚未核对；静态预览保留ROM初值。不是逐像素复刻某帧；浏览器RGB为3bit线性展开，不模拟显示器滤镜。

## 展示范围

65种当前地图非城池原码、8组城池样式的全部32个组合部件、四套调色板均解码通过。城池规模读ROM初始状态7AAB8+id×18+15低两位，统一使用非己方样式；不从人物初始关联推断实时城池归属。玩家、NPC、昼夜、天气、流水动画和临时状态不在本版静态预览内。地图未分配区域使用单色，明确不冒充已解码海洋。

原画代码src/rom/world-art.js及NativeWorldCanvas.jsx；截图诊断输出build/world-art/preview.png。原ROM、原存档不写入；无新正式ROM版本。地图编辑事务和权限不变。
