# 本地ROM记录

IndexedDB按当前站点保存最后一份ROM和已应用修改。数据留在当前浏览器，不上传，不跨设备同步。每次应用/撤销/重做后，保存工作字节的副本并重新计算MD校验和；保存队列按顺序提交，避免旧快照覆盖新快照。清除操作排在已有写入之后。

刷新自动校验并恢复；若用户同时手动加载新文件，旧恢复请求不会覆盖新选择。恢复后锁回查看模式，不保留密码授权，不恢复撤销历史或未应用弹窗草稿。带已有改动的恢复文件解锁后仍可导出。清除本机记录不会删除磁盘原文件；保存失败提示及时导出。

生产构建通过；已有29项测试通过，新增1项IndexedDB接口契约测试通过（保存/读取/清除、快照复制、提交顺序、失败后重试）。接口测试采用内存替身，不等于已验证浏览器磁盘、配额或隐私模式；当前浏览器控制接口不可用，刷新实测未完成。
