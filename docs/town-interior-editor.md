# 町内地图编辑

桌面载入 ROM → 地图 → 选中町 → 小眼睛打开详情 →「编辑町内地图」。编辑前通过原有钥匙解锁；查看模式和手机可以浏览原画，不能写入。也可从地图编辑工具的「町内地图」页进入。

- 下拉选择任意已识别町；当前正式版覆盖原版17町与新增13町。四季和缩放只改变预览。
- 直接按住建筑拖到空地，松手即完成；也可点建筑或右侧设施按钮，再点空地移动。设施门口自动同步，无需二次确认。Esc取消拖动，无效落点原子拒绝。精确定位可使用「输入坐标」。
- 院墙等组合景物使用「框选区域」，选完整组合后移动。目标应为空地。
- 选地形图块，拖动选区，再点「应用地形」；「吸取地形」可取现有地形。建筑、出生点、出口不可直接涂掉。
- 撤销、重做沿用整个工作副本的修改记录。修改后使用顶部「导出 ROM」，原文件不覆盖。

入口/出口及既有可达设施与建筑入口在应用前检查，堵路、越界、重叠建筑和切半已识别建筑会原子拒绝。院墙复杂造型由用户整组框选，不自动推测轮廓。不新增设施或改变设施服务类型。旧单町试验安装器没有独立设施表，其新增町不开放此编辑；常规原版町仍可编辑。

读取 world.layout-contract.v1 的场景索引、图块、入口表，设施表由实际原生引用0x2BCF2定位；不按发行文件名和版本号特判。修改仅涉及目标町图块及被搬动的设施门口四字节，无需重编大地图寻路。未来沿用相同目录格式的ROM可直接使用；未知格式停止写入。

验证：`tests/town-interior-edit.test.js` 合成边界用例与 TAIKOU_RELEASE_ROM 可选实际ROM往返；浏览器证据见 `docs/evidence/town-editor-qa.md`。当前v1.42.44导出后客栈(10,10)→(22,3)，五项设施实际开关与离开通过 `taikou-rebuild/reports/editor-town-shops-native-v142.json`。该内部验证ROM不发布。
